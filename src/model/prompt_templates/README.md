# Prompt templates

All behavioral instructions are plain-text templates loaded at runtime. The main contracts are `deepseek_backend.md`, `boundary_classifier.md`, `cat_tone_renderer.md`, and `kairos_reflection.md`.

Edit templates rather than adding prompt strings to Python, batch files, or YAML. Keep outputs in Simplified Chinese where the template requires it, and preserve the separation between content reasoning, classification, rendering, and memory reflection.
